primary_outcome [string]: The outcome(s) the paper designates as primary, each with its measurement instrument (full name and abbreviation, e.g. Patient Health Questionnaire-9 (PHQ-9)) and the primary time point if stated. Separate multiple outcomes with '; '. If the paper does not designate any outcome as primary, list its main outcomes and start the field with 'Not designated - '.
secondary_outcome [string]: The outcome(s) the paper designates as secondary, each with its measurement instrument (full name and abbreviation where given), separated by '; '. Return null if no secondary outcomes are designated, including when primary_outcome starts with 'Not designated - '.
analysis [string]: The main statistical analysis: the model or test used for the primary outcome (e.g. linear mixed model, ANCOVA adjusting for baseline), the analysis set (intention-to-treat or per-protocol), and how missing data were handled if stated (e.g. multiple imputation). For qualitative studies, name the analytic approach (e.g. thematic analysis). One to three sentences.
primary_results [string]: Results for each primary outcome: direction of the effect, the comparison and time point, and the statistics the paper reports, copied exactly (e.g. between-group effect size with 95% CI, test statistic, p-value). Separate outcomes with '; '. Do not compute any value the paper does not report.
secondary_results [string]: Results for the secondary outcomes, in the same style as primary_results but more briefly: for each outcome, the direction of the effect and the key statistic (effect size or p-value) if reported. If there are many, summarise the overall pattern and give statistics for the most important ones. Return null if secondary_outcome is null.
